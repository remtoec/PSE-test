01 留意故事入面嘅「想要」

模型喺故事見到啲乜？

模型逐句尋找三類動機主題。以下係兩種讀法，各有局限，冇一邊係標準答案。

數字係被辨認到主題嘅句子數目。一句可以有多個主題，亦可以冇主題。唔係分數、百分比或者高低評級。

原文分析可能漏咗廣東話表達；英文翻譯亦可能改變意思。兩條路線用同一個模型，一致唔代表準確。有出入嘅句子，正好值得望多眼。

三個主題，分別指啲乜？
成就
人物想做好一件事、達到標準、改善表現，或者克服挑戰。
連結／親和
人物想建立或維持關係、得到接納、照顧對方，或者重新連結。模型編碼親和，唔係 McAdams 特定嘅親密動機量尺。
影響力／權力
人物想說服、帶領、產生影響，或者爭取地位同控制。唔一定係負面：老師想改變學生、領袖想帶動團隊，都可以係想產生影響。

點解心理學會用故事研究動機？

模糊嘅圖片冇講明人物嘅目標，寫故事嘅人就要補上想要、衝突同結局。由 Murray 嘅 TAT 到 McClelland 等人發展嘅 PSE，研究者用有規則嘅內容編碼，探索故事中反覆出現嘅動機意象。

今次只係一個簡化、實驗性嘅體驗。自動模型未經驗證適用於廣東話，故事亦唔係你嘅自傳，唔可以用嚟判斷「真正嘅你」。

03 故事以外

人物想要嘅，
同你想要嘅呢？

一個人唔只係「平時點樣做」，亦有「想將事情帶去邊」。McAdams 將後者放喺 Motivated Agent 呢一層：我想要乜、重視乜，同埋正追求緊乜。

圖畫故事只係其中一扇窗。現實生活仲有你知道、講得出口嘅目標、計劃、人生項目同價值。

故事入面嘅「想要」同現實生活嘅「想要」未必一樣。兩者唔一致本身都可以好有意思，冇一個係「更真嘅你」。
諗一件你最近真係想做到嘅事。01 / 03

答案留俾自己就得。呢度唔需要輸入，亦唔會收集你嘅個人目標。

COMPETENCE / RELATEDNESS

你想做到啲乜，
又想同邊個連結？

呢個目標比較關於做到、掌握、產生影響（competence），定係建立、維持或者照顧關係（relatedness）？定係兩樣都有？

故事主題中，成就同影響力大致較接近前者；連結／親和較接近後者。呢個係理解角度，唔係換算分數。

INTRINSIC / EXTRINSIC

係件事本身有意思，
定係佢帶嚟嘅嘢？

你想做，係因為件事本身對你有意思，定係主要為咗回報、認同、責任或者其他外在原因？

同一個目標可以有幾種理由，唔需要揀一個先算答啱。

PROMOTION / PREVENTION

你想迎向啲乜，
又想避免啲乜？

你係想得到一個理想結果，定係主要想避免一個唔想發生嘅結果？

追求機會同守護已有嘅嘢，可以同時存在。

最後，返到你自己

你故事入面嘅人物想要嘅，
同你而家最想要嘅，係咪同一回事？

有呼應，可以諗落去。完全唔同，甚至「冇乜關係」，都係一個可以接受嘅答案。
