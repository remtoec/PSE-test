# 「畫中有你」文案檢視與結果頁提案

這次檢視以 `web/index.html`、`web/app.js` 的現有前台及下載文字，和你提供的 McAdams 書摘為本。目的：香港讀書會的暖場及講書引子。這是供你選擇的編輯提案，未更改正式網站或評分方法。

## 建議方向

**讓讀者先看見自己寫了甚麼，再開始想自己在追求甚麼。**

頁面應像一位讀過你故事的讀書會朋友：會指出一個意思，也拿出原句讓你看。它可以有觀點、有好奇心，毋須每說一句便收回半句。

敘事感來自人物的願望、阻力和選擇。把「主題」寫成人正在做的事，比增加抒情句更有效。解讀的主詞先是「你筆下的人物」，讀者自己的生活則用問題邀請他接上。

## 現有文案的主要問題

1. **解讀不斷被否定句打斷。** `frameText()` 的「唔代表你係某一種人，亦唔代表……只可以話……」，接着「點解要寫故事」、逐圖說明、反思、關於練習，再各自補一次限制。讀者聽到的往往是「這個結果沒有甚麼可說」。保留一處簡短方法說明，正文直接談故事。翻譯失敗等實際問題仍要在相關結果旁交代。
2. **換成粵語字詞，句法仍然抽象。** 「想要嘅筆墨比研究故事濃」「同人連結」「令自己嘅想法真正產生作用」都要再翻譯一次才能明白。「她想把實驗做好」「他希望大家照他的決定做」「她想再跟老朋友說話」讀起來就有場景。
3. **先解釋工具，後讓人認出自己的故事。** 現時先看研究比較、長條、限制，再看原句。建議先有一句解讀和一至兩句原文；讀者知道你在說甚麼，才看動機的名稱。研究參照及逐句標記放進展開內容。
4. **把影響力解釋得太正面。** 「唔一定係控制人」之後全是帶領、鼓勵，會削弱書摘最有意思的兩面性。可用「影響」作容易入口的標題，正文交代書中的「權力動機」：想讓事情照自己的意思發展，可以用來替人出頭，也可以用來壓過別人。
5. **理論層次太多。** 成就／連結／影響力上再加勝任感／歸屬感，後面又有自主、興趣、恐懼、證明自己。對暖場而言，像一次要教完兩課。先保留三種追求，較完整的理論關係留給你講書。
6. **結尾問得太多。** 三組反思題加兩個收尾問題，讀者容易沒有一題真的想下去。只留一條切身的問題和一個輕鬆的讀書會邀請；讓對話在現場繼續。

## 語氣怎樣選

| 方向 | 效果 | 取捨 |
| --- | --- | --- |
| 香港書面中文，少量口語（建議） | 像讀書會小冊子，短、自然，方便你在台上接着講 | 比現版少一些粵語字；靠句法和具體例子保留親切感 |
| 全粵語 | 像主持人直接跟讀者說話 | 可以成立，但要整句重寫，不能只把「的」改成「嘅」 |
| 文學式旁白 | 較有氣氛 | 容易變成每個人都適用的漂亮說話；宜只用在標題或收尾 |

示範採第一種。避免把「歐化」誤當成「不能用書面語」；真正要改的是抽象名詞、被動句、層層限定和重複解釋。

## 全流程的代表性改寫

| 位置 | 現有文字 | 建議 |
| --- | --- | --- |
| 首頁主題 | 每張圖，都係故事嘅中間。 | **保留這個意象。** 可改為「每張圖，都是故事的中間。」 |
| 首頁介紹 | 由人物想要嘅嘢，開始一場同自己嘅對話。 | 看四張圖，寫四個故事。讀書會上，再一起看看大家寫出了甚麼。 |
| 開始按鈕 | 開始：經典四張圖 | 開始寫故事；下面補「讀書會用這組圖，約 20 分鐘。」 |
| 寫作提示 | 人物各自諗緊咩、感受到咩、最想要咩？…… | 他們是誰？之前發生了甚麼？此刻在想甚麼、有甚麼感受？接下來會怎樣？（保留原練習要求；不預先透露三類動機。） |
| 提交前 | 準備好就睇結果：四個故事入面，人物反覆想要啲乜？ | 四個故事寫好了。一起看看，人物在追求甚麼。 |
| 等候 | 服務閒置時會休眠，第一次可能要等一分鐘。 | 正在整理故事中的主題，可能需要一分鐘。請先保持頁面開啟。 |
| 結果主標 | 今次故事入面，「成就」反覆出現。 | 你筆下的人物，想把事情做好。（用於成就主題有足夠材料的版本。） |
| 研究比較 | 你寫「想要」嘅筆墨比研究故事濃。 | 移到「看看分析詳情」，清楚寫「這些主題在你的故事中出現得較密集。」並保留比較來源；不再把它泛稱為一個人「想要」的多少。 |
| 逐句標記 | 冇主題 | 這句未標出三類主題。（沒有被模型標記，不等於句子沒有意思。） |
| 反思題 | 故事入面嘅「想要」，同現實一樣嗎？未必。 | 最近有甚麼事，你也很想把它做好？（隨結果更換。） |
| 結果保存 | 下載故事同結果 | 儲存故事和解讀；旁邊保留「離開前記得下載，重新整理後結果會消失。」 |

私隱、草稿保存、刪除、下一張後不能修改等操作事實應留在行動發生的位置。這些不是多餘的免責文字。

## 建議結果頁閱讀次序

1. **一句解讀。** 人物在追求甚麼，約一眼能讀完。
2. **故事原句。** 先認出自己的文字，再給一個貼着文字的讀法。原句必須原樣引用。
3. **書中的三種追求。** 成就、關係、影響；先展開今次有關的一項。用例子解釋，保留不同選擇的代價。
4. **為何從故事開始。** 一小段說明 Murray 的提問及這本書關心的「人想追求甚麼」。詳細歷史可展開。
5. **帶回生活的一問。** 由讀者自己判斷故事和生活的關係，不替他下結論。
6. **讀書會見。** 帶一句自己在意的話來，分享自願。最後才是分析方法、完整故事及保存。

「研究參照／逐句分析／英文譯文」可以保留在正式版的次要入口。示範刻意讓主閱讀線不依賴長條或分數；這是資訊次序提案，尚未改動現行計算。

## 怎樣有意思，又貼着書摘

- 可以說「這幾句都在寫人物如何爭取別人的認同」，不直接跳成「你一直渴望被認同」。有觀點和斷定讀者人格是兩回事。
- 成就包括精進、達到標準、克服挑戰；不要全部寫成好勝或完美主義。
- 權力保留讓自己有分量、影響別人、左右事情的意思；不只美化成助人，也不一律貶作控制慾。
- 前台以「關係」涵蓋想被接納和想親近。書摘中的 affiliation 和 intimacy 有分別，現有模型的 `aff` 並非獨立的 intimacy 分數。不要由這個標記推論讀者善良、善於聆聽、幸福或某種依附型態。
- 書摘提到家庭、學校和故事如何傳遞價值，適合做講書引子：「我們怎樣學會覺得某些事值得追求？」不由四篇故事追溯個人的童年成因。
- 結尾借用書摘「目標隨人生處境改變」的方向，把注意力放在「此刻」。不做固定人格分類。
- 故事的敘事感是人物有所追求、遇到阻力、作出選擇；這不等於宣稱四個虛構故事就是讀者的自傳或 narrative identity。

## 示範及正式接入的分界

`mockups/results-copy.html` 可離線開啟，有成就、關係、影響、多種追求、線索較少、暫有線索六種文字。所有故事片段及片段讀法均為編輯示例，沒有連接模型或參加者資料。

示範中的逐句讀法為人工撰寫，用來決定語氣。正式版若仍只使用現有分類器，應用原句配上主題的通用解釋，不可假裝系統已能理解人物的具體情節。三個強主題標題只在現有足夠材料的條件下使用；微弱或不穩定的結果用「暫有線索」，不能只刪除限定詞而沿用強結論。

「多種追求」示例假設確實標到多種主題。現有 `balanced` 表示接近圖片的研究比重，並不自動等於三種追求同樣多；接入時須按實際標記選文案。有並列主題則並列呈現，不強挑一個。

「線索較少」仍然讓讀者回到故事，但不虛構整體解讀。缺少研究參照時可談實際標到的主題而不作跨樣本比較；翻譯未完成時另顯示「英文翻譯未完成，以下只按原文整理。」這些情況不可用抒情句遮蓋。

若採用，需一併更新 `resultText()` 下載文案，避免畫面和下載檔各說一套。此輪只交文案提案與獨立 HTML，正式接入及部署留待你選定方向。
