# 經典四圖測試故事

按讀書會四圖的出場順序貼上，每幅圖使用一段。這組故事刻意涵蓋成就、關係和影響，方便觀察結果頁怎樣整理故事中的不同追求。

## 1. 拳手

阿健剛輸了一場拳賽，坐在場邊，最不甘心的是自己又犯了同一個錯。教練說他已經打得不錯，但他想知道，為甚麼每到第三回合就守不住。他回去重看片段，記下每次失分的位置，決定用六個星期練好步法，再找實力相近的拳手試一次。每天收操前，他都請教練指出一個有進步和一個要改的地方。下一場他仍然輸了，卻第一次撐足全場，沒有亂了節奏。他走下擂台時笑了，因為這次終於知道，自己的苦功用對了地方。

## 2. 河邊二人

兩姊弟約在河邊見面。自從上次為照顧媽媽的事吵架，他們已經一個月沒有好好說話。姐姐本來準備了一肚子道理，見到弟弟一臉疲倦，卻只問他最近睡得好不好。弟弟沉默了一會，才說自己不是不想幫忙，而是怕做甚麼都不合她心意。她聽完沒有反駁，只說：「原來你一直咁諗，我真係唔知。」他們沿着河慢慢走，談起小時候一起放學的事。事情還未全部解決，但臨走前，弟弟問她星期日要不要一起吃飯，她立即說好。

## 3. 實驗室

敏儀和同事已經重做了三次實驗，每次的數字都不一樣。明天就要匯報，同事提議先挑最好看的一組，她卻想弄清楚問題出在哪裏，否則交了報告也不安心。她把步驟逐項列出，兩人分工檢查溫度、時間和儀器，終於發現其中一部儀器沒有校準。這次她們先定好誤差範圍，再重新做一遍，結果終於能夠重複。敏儀鬆了一口氣，把同事叫過來一起看。第二天匯報時，她特別提到同事找出的關鍵，因為這份成果是兩個人一起捱出來的。

## 4. 船長

船快要離港，岸上卻傳來天氣轉壞的消息。老船員認為照常出發就可以，新上任的船長知道，如果這次沒有人聽他的，以後每個決定都會被架空。他召集各人，把航線和風勢攤開來講，堅持改道，並逐一安排誰負責甚麼。有人嫌他小題大做，他當着全體船員說，延誤由他向公司交代，但船上必須有一致的指令。最後大家照他的安排工作，船也平安到港。看着原本不服氣的船員主動來問下一程怎樣走，他感到自己終於站穩了船長的位置。
